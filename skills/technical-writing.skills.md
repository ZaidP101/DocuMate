# Technical Writing Skill

## Description
Produces clear, accurate, and audience-appropriate technical documentation. Ensures consistency in terminology, tone, and structure across all generated files.

## Guidelines
- Write in active voice and present tense
- Use descriptive section headings (not "Introduction" — be specific)
- Prefer numbered steps for procedures, bullet points for lists
- Include code examples for installation and API usage
- Keep language concise — one idea per sentence

## Application in DocuMate
Used by README generation and Dockerfile documentation to produce human-readable content. Validates that generated text follows these guidelines.

## Checklist
- [ ] Active voice used throughout
- [ ] Steps are numbered where order matters
- [ ] Code blocks have language annotations
- [ ] No vague or filler phrasing
- [ ] Consistent terminology with project domain
